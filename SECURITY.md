# Security reporting

Please report vulnerabilities privately to mission@gomission.io. Include an
affected package/version, impact, and a minimal reproduction with synthetic
data. Do not post live credentials or private workspace data in public issues.

This stable branch reproduces the published @gomission/mcp 0.2.3 runtime.
The local Mission chat bridge remains unavailable until a supported
workspace-scoped authentication handoff is implemented and reviewed.
Approval review and receipt tools are not a substitute for provider-side
execution authorization. This release is not a security certification.
